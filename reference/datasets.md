# Get datasets of XenaHub object

Get datasets of XenaHub object

## Usage

``` r
datasets(x)
```

## Arguments

- x:

  a
  [XenaHub](https://docs.ropensci.org/UCSCXenaTools/reference/XenaHub.md)
  object

## Value

a character vector contains datasets
